# Motion and interaction spec

- **Hero and scroll reveal:** The inspected Webflow `slideInBottom` preset begins at opacity 0 and a vertical offset, then resolves over 1000 ms with `outQuart`. The hero uses a larger entrance movement; section reveals use a restrained 24 px offset so their transformed boxes remain inside the measured ScrollTrigger threshold and do not appear missing above the fold. Scroll reveals trigger around 84% of viewport height.
- **Dropdown and menu:** The reference dropdown opens its icon and content over 400 ms; closing uses a 300 ms icon rotation and a 200 ms content collapse with a short opacity delay. The local Pages dropdown uses a native `<details>` control and CSS transitions. The reference hamburger uses a 400 ms Lottie animation; the local two-line icon animates in CSS to avoid copying its asset.
- **Buttons:** Reference primary button hover in/out lasts 400 ms and moves the text/icon while scaling/fading the background. Local buttons use CSS color/transform transitions at the same 400 ms scale, with keyboard focus feedback.
- **Service list:** Source service rows are approximately 128 px tall at rest and expand to about 552 px on hover, with a yellow `#FBEA69` background and a 424 px answer area. The local rows reveal the complete service description over 400 ms, preserve a concise summary on touch layouts, and keep the detail page link usable.
- **Projects:** Reference project hover scales the image from 1 to 1.1 and reveals a circular action over 400 ms. Local original concept photographs scale gently and reveal a circle arrow on hover and keyboard focus; the separate case-study interface preview remains labeled as illustrative.
- **FAQ and feature tabs:** Reference FAQ disclosure expansion, border, and plus/minus icon transitions take 400 ms. Feature panel height/opacity transitions take 400 ms; the selected tab background takes 500 ms. Local native FAQ details remain keyboard-accessible; feature panels animate their height/opacity over 400 ms.
- **Observed measurements:** The desktop reference H1 was Anton 112/112 px with -1.12 px tracking; H2 was 64/76.8 px with -0.64 px tracking. A service row measured about 128 px before hover and 552 px open. These measurements were collected from the live reference on 2026-11-16.
- **Reduced motion:** `prefers-reduced-motion` selects a no-motion setup through `gsap.matchMedia`; CSS also disables decorative motion and scroll transitions for reduced-motion users.
- **Hero ticker:** CSS marquee repeats skill areas as a text ticker. It pauses or becomes static when reduced motion is requested.
- **Project slider:** Previous/Next controls scroll a native horizontal track with smooth scrolling and snap points. The track remains manually swipeable on touch devices.
- **Intro features:** Three accessible tab buttons reveal one panel at a time and update `aria-selected`/`aria-controls` state. The outgoing panel closes immediately and the incoming panel animates height and opacity over 400 ms; reduced-motion preference disables this transition.
- **Pricing selector:** The selector highlights a service scope and updates the visible quote-oriented card; it does not change an invented price or claim a price estimate.
- **Mobile navigation:** A button toggles the mobile links, updates `aria-expanded`, closes on Escape, and returns focus to the menu button.
- **FAQ:** Native `<details>/<summary>` controls work without JavaScript and preserve keyboard behavior.
- **Contact status:** Form submission announces pending/error/confirmed states using an `aria-live` status region. Email is described as delivered only after the server endpoint receives provider acceptance.

The visual capture script preserves scroll-triggered movement, waits for fonts and image decoding, and pauses only infinite looping animations before measuring. Animated video comparison was not possible because video generation tools were unavailable and the original reference media is not reused.
